# Gustavo & Ana — Nosso Amor

Site romântico responsivo com contador, carta, animações e galeria de memórias.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie todo o conteúdo deste ZIP para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
5. Clique em **Save**.

Não é preciso instalar nada: o site é totalmente estático.
